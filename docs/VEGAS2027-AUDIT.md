# Аудит и проверка VEGAS Pro 2027 Build 31

Дата: **22 октября 2026**, форк `2.1.1-vegas2027.31`.
Исходник: [United Taps / vegas-pro-mcp](https://github.com/unitedtaps2/vegas-pro-mcp),
ревизия `4930a5df556fdeeab5b622b36c8a516b008a0651`, MIT.
Форк: [RockZe / vegas-pro-mcp](https://github.com/RockZe/vegas-pro-mcp).

## Результат

Сервер и C#-расширение собраны, установлены и реально работают в
**Boris FX VEGAS Pro 2027.0.0 Build 31**. Файловые версии исполняемого файла
и `ScriptPortal.Vegas.dll`: **2027.0.0.31**. Нативный статус возвращает
`Version 2027.0.0 build 31`. Рядом установлен VEGAS 23; его путь не использован.

Все 9 инструментов и 100 исходных маршрутов сохранены. Это не означает,
что все комбинации параметров, плагины и 100 действий полностью проверены.
Машиночитаемый итог без приватных путей: [vegas2027-validation.json](vegas2027-validation.json).

## Архитектура и совместимость

| Компонент | Назначение и результат аудита |
| --- | --- |
| `src/server.mjs` | MCP STDIO на официальном MCP SDK; каталог из 9 инструментов, 100 действий; проверка входных параметров до отправки в редактор. |
| `src/pipe-client.mjs` | Поиск экземпляров по локальным JSON-записям, проверка PID и имени процесса, токен, UUID запроса, deadline, ограничения ответа. |
| `VegasMcpExtension.cs` | `ICustomCommandModule`, именованный канал с ACL текущего SID, проверка токена, выполнение через UI dispatcher VEGAS. |
| `VegasActions.cs` и partial-классы | Проект, монтаж, группы, звук, медиа, OFX и движение; общая защита пути/идентичности, резервная копия перед Undo. |
| `RenderManager.cs` | Нативный асинхронный render API, шаблоны, job ID, прогресс и отмена; запрет существующего выходного файла. |
| PowerShell-скрипты | Компиляция .NET Framework x64 против локального API, проверка версии, установка, запуск, настройка Codex, диагностика. |

Исходная C#-сборка компилировалась против установленного API 2027 без изменений
сигнатур. Подтверждены доступность `ICustomCommandModule`, `UndoBlock`,
`CloneProject`, событий и групп таймлайна, OFX API, Pan/Crop, Track Motion,
`BeginRender` и событий рендера. Проприетарная DLL API не копируется в форк
или установочный архив. Для сборки используется локальная установка VEGAS.

Исходные тесты прошли до внесения изменений: 30 Node-тестов, MCP smoke,
12 сценариев алгоритма удаления диапазона и установочный fixture.

## Внесённые изменения

1. **Точный выбор хоста.** У исходника сборка искала только каталоги VEGAS 2026,
   а клиент принимал любой `vegas*.exe`. Теперь проверяются EXE, API и версия
   `2027.0.0.31` при сборке, установке, загрузке/выполнении расширения и выборе
   экземпляра. Явный `vegas_pid` не обходит проверку. Добавлен поиск в реестре.
   В несовместимом хосте расширение не создаёт канал и команды меню.
2. **Установка.** Manifest содержит версии и SHA-256 API/DLL. `-SkipBuild`
   отказывается устанавливать изменённую либо несоответствующую DLL.
   Существующие DLL/manifest сохраняются, токен не заменяется. Проверка
   процессов через `Get-Process` работает без WMI; перед копированием она повторяется.
3. **Track Motion.** Реальный тест обнаружил `TrackMotionInitialize` →
   `E_UNEXPECTED` при чтении вне Undo-контекста. Чтение выполняется во временном
   отменяемом Undo-контексте. Проверены повторное чтение, неизменность флага
   модификации проекта и сохранение Undo/Redo после чтения.
4. **Надёжность.** В имена `.veg`-копий добавлен GUID: операции в одну миллисекунду
   не используют одно имя. Чтение входной строки ограничено до её полной загрузки
   и имеет 15-секундный deadline. Неактивный клиент освобождает канал.
   Короткий повтор соединения допускается только до первого подключения/отправки;
   уже отправленные изменения никогда автоматически не повторяются.
5. **Зависимости.** Zod обновлён с 3.25.76 до **4.6.7**, схема record переведена
   на совместимую сигнатуру. MCP SDK **1.32.1** сохранён: он поддерживает Zod 4
   и не имел доступного обновления на дату проверки. `npm outdated` пуст,
   `npm audit --omit=dev` сообщает 0 известных уязвимостей.
6. **Codex и диагностика.** Настройка STDIO с абсолютными путями, корректной
   обработкой кириллицы и пробелов, защитой от конфликта имени, резервной копией
   конфигурации и таймаутами 30/210 с. Добавлены launcher точной версии,
   doctor, MCP probe, JSON-диагностика stderr и ограничение журнала расширения.

Обработчики работающих функций сохранены. Не добавлены операции удаления
исходных медиа, произвольное выполнение кода или автоматическая замена проекта.

## Что проверено реально в VEGAS

Среда: Windows x64, Node **24.19.0**, Windows PowerShell 5.1,
локальный .NET Framework и реальная DLL расширения **2.1.1.0**.
Тесты создавали собственные `.veg`, BMP, WAV и AVI в `work/live-*`.
Рабочие проекты пользователя для изменений не использовались.

Прошёл **21 сценарий** с **60 различными успешными прямыми MCP-действиями**;
дополнительно `timeline.set_fades` выполнен внутри пакетной операции.
Полный перечень проверенных и оставшихся действий находится в JSON-итоге.

- Реальный handshake MCP STDIO, девять инструментов, каталог 100 действий,
  переход через именованный канал к установленной DLL, точная идентичность Build 31.
- Создание дорожек, вставка видео/PCM-аудио, перемещение, обрезка, разрезание,
  копирование, удаление, чтение фактических диапазонов после операций.
- Создание `.veg`-копий до изменений, именованные Undo-блоки, нативные Undo/Redo;
  отменённая операция оставляет состояние неизменным.
- Dry run и применение batch, один результат/backup/Undo для пакета.
- Громкость аудиособытия, нативная peak-нормализация, микшер дорожки,
  точки огибающей, аудиошина, маршрутизация и микшер шины.
- Медиа-список, bin, дубли, смена активного дубля, удаление лишнего дубля,
  замена медиа с сохранением предыдущего, последовательность изображений.
- Pan/Crop, ключевые кадры Track Motion и их чтение, числовая проверка значений.
- Штатный OFX **Brightness and Contrast**, поиск пресетов, добавление эффекта,
  изменение параметра с анимацией, эффект дорожки и bypass. В предшествующем
  успешном прогоне также проверен установленный **BCC Brightness-Contrast**.
- Маркеры, регионы, установка курсора и диапазона выделения.
- PNG snapshot: файл создан, изображение визуально просмотрено. Повторная
  запись в тот же путь отклонена.
- Нативный асинхронный WAV-рендер: статус `Complete`, выход **384084 байта**.
  Дополнительно проверены PCM 16-bit stereo, 48000 Hz, 2 секунды и ненулевой сигнал.
- Нативный AVI-рендер `Video for Windows / Default Template (uncompressed)`:
  статус `Complete`, выход **23390720 байт**, 1 секунда с видео и звуком.
  AVI импортирован обратно; связанные A/V-клипы сгруппированы. Проверены
  перемещение, копирование, разрезание, удаление групп и Undo.
- Реальный отказ неверному токену, просроченному запросу, другому project_path,
  устаревшей идентичности клипа/настроек, изменению одного сгруппированного
  клипа, batch без подтверждения и перезаписи snapshot/render.
- Подключившийся без запроса клиент отключён по deadline; следующий MCP-запрос
  проходит после переоткрытия канала. Исходные BMP и WAV сохранили SHA-256.
- Реальная резервная копия открыта в новом процессе Build 31. Дорожки,
  имена/диапазоны событий, пути медиа и группировка совпали с финальным
  таймлайном; `is_modified=false`. Затем открыт исходный тестовый проект.
- Сервер **vegas-pro-2027** зарегистрирован в Codex; CLI повторно прочитал
  команду и таймауты. Запуск сервера и инструменты проверены отдельным MCP-клиентом.
  Текущему чату Codex для появления новых инструментов требуется переподключение.

Приватные полные отчёты: `acceptance-report.json` и `backup-reopen-report.json`
в каталоге соответствующего `work/live-*`. В Git и архив они не включаются.

## Что проверено только автоматически

- **35 Node-тестов**: паритет 100 маршрутов, проверки project/event guards,
  discovery, неверные версии/PID, redirected Documents, фрагментированные ответы,
  UUID, разрывы/таймауты и восстановление соединения без повторной отправки.
- Тест изменения Codex TOML на отдельном fixture: остальные таблицы сохранены,
  исходная конфигурация скопирована, повторный запуск ничего не меняет.
- **12 сценариев алгоритма ripple-delete** с моделями таймлайна, компилирующими
  производственный C#-метод. Это не реальные объекты VEGAS.
- Изолированный установочный fixture: установка/обновление, защищённый токен,
  его сохранение, rollback DLL/manifest, отказ подменённой DLL, другой сборке
  и активному старому процессу. Полная установка также выполнена реально,
  но на отдельном чистом Windows-профиле не проверялась.
- Синтаксис JavaScript и PowerShell, компиляция всех C#-файлов против локального
  API Build 31, аудит locked npm-зависимостей.

## Что осталось неподтверждённым

- Остальные маршруты из JSON-перечня и все возможные комбинации их параметров.
  Они сохранены и компилируются; нативное успешное выполнение для них не заявляется.
- LUFS-анализ/применение: FFmpeg на PATH не найден. Эти функции сохраняются;
  требуется FFmpeg либо явный `ffmpeg_path`. Нативная peak-нормализация проверена.
- Аппаратный рендер NVENC/AMD/Intel, MP4/HEVC/AV1 и все прочие шаблоны,
  длительные/отменённые рендеры, все декодеры и сторонние OFX.
- Нативные граничные сценарии `ripple_delete`, автоматизация/группы при его
  разрешающих флагах. Сохраняются ограничения исходного контракта: автоматизация
  и ключевые кадры не сдвигаются, восстановление групп не обещается.
- Субъективная оценка изображения/звука, весь проект в реальном времени,
  визуальная идентичность всех плагинов и всех параметров восстановленной копии.
  Снимок просмотрен, аудиоданные проверены численно; прослушивание не заявляется.
- Параллельные несколько экземпляров Build 31, другая учётная запись Windows,
  сетевые/OneDrive-проекты и чистая переустановка Windows.
- Другие сборки VEGAS: они целенаправленно не поддерживаются этим форком.

## Воспроизведение

```powershell
npm ci --ignore-scripts
npm run check
npm run smoke
npm run test:native
npm run test:installer
npm run build
npm run doctor
npm run probe
# Далее только при закрытом VEGAS:
npm run test:live:prepare
npm run test:live
node tests/backup-reopen.mjs
node scripts/summarize-validation.mjs
```

Тест повторного открытия закрывает только проверенный собственный fixture,
открывает созданную им резервную копию и возвращает исходный тестовый проект.
Для использования: [русская инструкция](../README.ru.md).
